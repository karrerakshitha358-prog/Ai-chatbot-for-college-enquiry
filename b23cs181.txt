from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

# Load dataset
data = load_iris()
X, y = data.data, data.target

# Split data
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# Train model
model = LogisticRegression(max_iter=200)
model.fit(X_train, y_train)

# Predictions
y_pred = model.predict(X_test)

# Accuracy
acc = accuracy_score(y_test, y_pred)
print("Accuracy:", acc)

Q2: Quantum Computing, PQC & AI Security – Short Answer
1. Threat of Quantum Computing to RSA & ECC
RSA & ECC security depends on hard math problems:
RSA → Integer factorization
ECC → Elliptic curve discrete logarithm
Quantum algorithms:
Shor’s Algorithm can solve both efficiently in polynomial time
👉 Result:
Once large-scale quantum computers exist, RSA and ECC become breakable
Most current internet security (TLS, banking, VPNs) is at risk
2. Role of AI in Building Quantum-Safe Systems
Secure Data Pipelines
Encrypt data using Post-Quantum Cryptography (PQC) algorithms
Use hybrid encryption (classical + PQC during transition)
AI helps detect abnormal data flow or breaches
Model Protection
Secure AI models using:
encryption of weights
secure enclaves (TEE)
watermarking models against theft
Privacy-Preserving Learning
Techniques:
Federated Learning
Differential Privacy
Homomorphic Encryption
AI ensures training without exposing raw data
3. Defensive Strategies
Post-Quantum Cryptography (PQC)
Lattice-based cryptography (e.g., CRYSTALS-Kyber, Dilithium)
Resistant to quantum attacks
Standardized by NIST
Secure Communication
Quantum Key Distribution (QKD) for ultra-secure key exchange
Quantum-resistant TLS protocols
AI-based Threat Detection
AI models detect:
intrusion attempts
abnormal cryptographic behavior
zero-day attacks
Real-time security monitoring
4. Offensive Risks
AI can be misused for:
automating cyberattacks
phishing and social engineering at scale
finding cryptographic weaknesses faster
Future risk:
AI + quantum computing could accelerate password/key cracking attempts
Deepfake + AI-driven fraud increases security threats
5. Practical Steps for Organizations (Today)
Start migration to Post-Quantum Cryptography (PQC)
Implement crypto-agility (ability to switch algorithms quickly)
Use hybrid encryption systems
Adopt Zero Trust security architecture
Secure AI pipelines with encryption + access control
Invest in AI-based cybersecurity monitoring tools
Train developers in quantum-safe cryptography standards
6. Conclusion

Quantum computing poses a serious long-term threat to RSA and ECC, but Post-Quantum Cryptography and secure AI systems provide a strong defense path. Organizations must transition early, adopt crypto-agile systems, and integrate AI-driven cybersecurity to stay resilient in a quantum future.
